## Getting Started

1. **Clone this repository:**
   ```bash
   git clone https://github.com/prendle-aureaquantra/pbip-automation-gold.git
   cd pbip-automation-gold
   ```

2. **Review the documentation:**
   - See `docs/` directory for guides
   - Check `templates/` for available PBIP templates
   - Review `examples/` for usage examples

3. **Generate your first PBIP:**
   ```bash
   python generate_pbip.py --template sales-dashboard --output my-dashboard
   ```

4. **Open in Power BI Desktop:**
   - Open the generated `.pbip` folder in Power BI Desktop
   - Connect your data sources
   - Customize as needed
   - Save as `.pbix` when ready
