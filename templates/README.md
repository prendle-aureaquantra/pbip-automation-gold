# Templates

`themes/LuxeOnyx.json` is a dark report theme: onyx canvas, champagne-gold accents, Georgia titles. Pass it to `write_project(theme=...)`, or import it in Desktop with View > Themes > Browse for themes.

No template configs are checked in yet.

The working sample is the sales report written by:

```bash
python3 src/pbip_generator.py
```
