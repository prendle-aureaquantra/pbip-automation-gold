# Examples

Open `SalesReport/SalesReport.pbip` in Power BI Desktop.

The model is one `Sales` table (Region, Amount) and a Total Revenue measure. The four rows are stored in the model, so the file does not depend on a path on your machine.

`python3 src/pbip_generator.py` writes a separate generated project under `output/`. That output is not the checked-in example.
