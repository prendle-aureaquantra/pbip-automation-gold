# Installation

## Prerequisites

- Python 3.8 or newer
- Power BI Desktop
- Git

## Steps

1. Clone the repository:

```bash
git clone https://github.com/prendle-aureaquantra/pbip-automation-gold.git
cd pbip-automation-gold
```

2. Run the sample generator:

```bash
python3 src/pbip_generator.py
```

3. Open `output/SalesReport.pbip` in Power BI Desktop.

No license file is required.
